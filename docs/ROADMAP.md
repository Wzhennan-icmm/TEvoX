# Roadmap

## P0 — completed in 0.2.0-alpha.1

Locus CIGAR projection, paired-flank evidence, strict validation, uncertainty
states, deterministic outputs, golden/regression tests, license and CI.

## P1 — completed in 0.2.0-alpha.1

Multi-genome manifest, orthology candidate graph, global quota-constrained
selection, WGD/co-ortholog support, quality scoring and tree-aware Fitch events.

## P2 — required before submission

Independent biological/simulation benchmarks, score calibration, interval
indexes and streaming graph construction, nested/fragmented TE models, family
ontology normalization, branch-length-aware ancestral inference and reproducible
benchmark containers/figures.
